## Result 1: model picker retrained on 762 dev transitions (job `picker-cv-1124`, done 1:36 AM; script `protrans/replica/picker_1124.py`, analysis `analyze_1124.py`)
Plain words: for every pair the model chooses where to leave the outgoing track (exit), where to start the incoming one (cue) and the blend length (16 or 32 bars), from the two tracks' contents only (the "style-free" primary arm; it never sees what the pro did earlier in the same mix). "Leave-one-DJ-out" = for each DJ, train on everyone else and test on that DJ, so nothing leaks. Error = bar distance from what the pro did (lower is better). "Gate" = the model only overrides the default when it is confident (abstains otherwise). 95% CI = grouped bootstrap by mix (4000 draws); a win needs the CI to exclude zero.

Data: 762 dev transitions, 89 mixes, 25 DJs (11-20: 437/47/17). All fresh-ledger mixes (62 transitions) and the locked Liquicity/Hospital holdout (34) excluded. Neither was touched tonight.
