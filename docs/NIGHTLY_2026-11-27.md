What this means: only the pumping check really works. The bass-hole and clash checks almost never see the injected faults, so a "0 fails" on those two means little.

Why, and recalibration candidates (pro p95 + injections only, nothing loosened, none adopted tonight):
- **Bass hole.** The official number is "lows before the blend minus the lowest lows anywhere in the blend", so planned bass drops count and the pro p95 sits at 45 dB. Also the 150 Hz band leaks 150-300 Hz kick/bass harmonics through its 4th-order filter, which hides a cut below 150 Hz (injected 4-bar hole moves the 150 Hz curve only a few dB). Candidate `lows_hole` (`hchole_1127.py`): width-aware V-dip (the lows go down AND come back) of the summed sub-bass below 90 Hz, threshold = pro p95 of the same number on the 33 pro clips (25.2 dB). **Detection 76% (hole4) / 61% (hole8), clean flags 18% (6 / 33).** In the 150 Hz band the same measure catches 3%. I looked at the clean flags against the rendered audio: they are real sub-bass gaps, not detector noise. Example `hybrid_minds_ukf__25`: sub-bass drops from −22 to about −52 dB for 8 bars mid-blend (outgoing bass is gone before the incoming bass arrives); `__12`: about −64 dB for 8 bars; `wilkinson_boomtown2026__33`: 2 bars at −53/−59 plus one bar at −67. Pros exceed this p95 on 2 / 33 clips; our default on 6 / 33. So the default has more real bass gaps than the official check reports. Not gated tonight: it needs an ear check and a fix in the bass swap first (lead for next night: swap the bass only once the incoming has sub-bass).
- **Clash.** The official lag cross-correlates deck A against deck B (two different tracks) and answers only when ≥3 bars agree, so on most pairs it returns "no confident lag" with or without the fault. A wider bar set (`hcclash_1127.py`, same rules otherwise) did not help (12% / 6%) but cut the hole8 false clash flags 18% -> 6% (n1126's `wilkinson_boomtown2026__33` type). A per-deck beat-phase measure calibrated on the pro clips (`hcphase_1127.py`) is too noisy: pro p95 73 ms, clean renders median 42 ms, flags 27% clean vs 36% injected. **Rejected.** The clash check stays as is and must not be read as strong evidence of "no clash".
