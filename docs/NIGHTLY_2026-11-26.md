What we learned:
- **ridegate passes all three dev conditions again** on 19% more data (beats default and majority with CIs below zero, no metric clearly worse). The gain is a bit smaller than last night (−2.44 vs −3.39): the new rows are mostly KushSessions mixes where the pro rides to the outro more often.
- **The tail-exit option did not help.** It covers the pro's choice far better (exit within 8 bars 77% -> 92%), but the ranker uses it on 26% of pairs and the exit error barely moves on the pairs where the pro really did enter in the last 12 bars (ridegate 32.8 -> 31.3 bars; default 14.2). It also costs a small but real blend-length error (8-bar blends where pros used longer ones). Coverage was not what limited the tail pairs: the damage on them comes from the model jumping out mid-track, not from missing a tail option.
- Where the errors come from (exit error by what the pro did): pro left mid-track (514 pairs): default 76.9, ridegate 56.4; pro rode to the outro (224): default 7.8, ridegate 26.5; pro entered in the last 12 bars (263): default 14.2, ridegate 32.8. Same pattern as 11-24/11-25: the win comes from "leave earlier more often", paid for on ride pairs.
- The ride-vs-leave classifier is still near a coin flip from the two tracks alone (AUC 0.569; 0.5 = coin flip). With the pro's earlier transitions in the same mix it reaches 0.705 and the exit error on ride pairs falls to 16.1: again, **most of the exit signal is DJ habit, not track content**.
- Worst ridegate pairs are all "pro rode to the outro, model left ~100 bars early" (alpha_rhythm_lDm7CmhTPzE__09 +63, kushsessions_T86wusWVRuU__14 +55, mrmommusic_7j4WQ5qOBZY__20 +54). 8 of 27 DJs are worse than default (Alpha Rhythm +5.6 over 69 pairs is the biggest real one). 451 pairs better, 354 worse, 196 the same.
