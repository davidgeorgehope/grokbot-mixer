## Why the exit is still hard (diagnosis, post-hoc, does not count toward promotion)
Ride-vs-leave classifier, leave-one-DJ-out AUC on dev (0.5 = coin flip, 1.0 = perfect), `nightly_1125_work/ride_explore.json`:

| features | AUC |
|---|---|
| tonight's frozen gate (pair features: lengths, drop counts, outro length, bass by section) | 0.581 |
| richer pair features (outro vs drop energy/drums/bass, last-drop-to-end, incoming intro energy, position in mix, BPM) | 0.599 |
| richer + what the pro did earlier in the same mix (online, strictly earlier transitions) | 0.691 |

Plain words: from the two tracks alone we can barely tell whether a pro will ride to the outro or leave mid-track; most of the signal is the DJ's habit within the mix. That explains why every exit model so far gains on "leave" pairs and loses on "ride" pairs: the choice is mostly style, not track content. For the listener's own mixes there is no pro history to read, so the honest target for the exit is "an acceptable, clean exit" (any phrase boundary that passes the hard checks and that the listener rates well), not "guess this DJ's habit".
