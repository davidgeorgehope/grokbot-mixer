## Ranked causes

### 1. The time hint never sees mid-track windows (root cause)

`recreate.py` only re-ranks the ~10 family winners from `blend_bench.families()`. That helper keeps the *lowest engine-cost* natural 16-bar and 32-bar windows. `mix_simple.pair_cands` gives the outro-over-intro STRUCT window a 300-point bonus (`STRUCTW=300`). On this pair that winner is `["n", 176, null, 32, 16]`, engine cost −187.7. The next natural 16-bar window, without the bonus, costs +46 and never becomes `nat_short`.

The hint is doing what it says — `hint_weight=0.15`, `near_hint_bars=32`, hint bar 95, cost `0.15 * |176 − 95| / 32 = 0.38` — but it can only compare family winners, and those winners are almost all outros. On the current default checkpoint (`d1115_xp_045`, train 32.26 / test 34.05) 32 of 33 pairs are `nat_short`, and most outgoing ends sit 50–200 bars past the hint. The 11-13 pick (Sabre -> Pretend, score 12.09) is 192 bars late. This is a general shortlist bug, not a per-track pin.

A near-hint 16-bar window already exists: `["n", 112, null, 48, 16]` (Prime Expansion 96–112, Demons 48–64, the first drop, full bass). Engine cost 126.8, 17 bars from the hint. `["n", 96, null, 48, 16]` is even closer (1 bar) but costs a little more. Neither is ever nominated.

Code path: `mix_simple.pair_cands` (STRUCT bonus) → `blend_bench.families` (`best()` by engine cost) → `recreate` hint term, which never sees e=96 or e=112.

### 2. A 22.5 dB bass hole, from cause 1

Demons' intro (bars 32–48) has no bass yet. We still hand the lows over (designed swap [164, 169], and `swap_before_thin` can pull that earlier when the whole incoming window is thin) while Prime Expansion is in a full second drop (−17 dB). The rendered start-of-blend drop is 22.5 dB. This is not a hole in the source: Prime Expansion's lows only die at bar 184. It is the engine cutting a full drop into a thin intro.

The predicted feature used in the fix is exactly this: bars where incoming lows sit more than `GAP_DB=9.84` (pro p95) under the incoming body, while outgoing lows are still within `GAP_DB/2` of *its* body. This pair has 14 such bars. A musical breakdown, where both records are already thin, does not count.

### 3. Not a trainwreck, and not the lingering-fade work

- Half-beat gate did not fail. The old window had too few drum-on-drum bars to measure; beat phase on the new window is 0 ms over 16 drum bars (pro_lock still ~5 ms). A few mid-blend bars in the fix sit ~150 ms off; the official gate still passes. Median offset 14.5 ms.
- No clipping (ours peak about −3 dBFS).
- Keys are not in the library for these two tracks (`None->None`), so a Camelot clash was not the measured failure. Vocals were not scored (no vocal maps); the vocal stem subscore stayed ~23.
- Tempo stretch is the usual 173 → 174 on Prime Expansion; rate 1.0, not a broken grid.
- The short 3–5 bar audible overlap vs the pro's 18, and the leftover 2-bar kick lag after the window move, are mostly section/shape symptoms. How long a blend should last is itself a per-pair choice, which is why this RCA does not touch FADE=long, SNAP_IN, or TAIL_*. X1 is unchanged.

## Fix (`hint_family`, off by default, per-pair)

When `rules["hint_family"]` is on, `recreate.add_hint_families` *may* append `hint_short` and `hint_long`: the lowest engine-cost natural 16-bar and 32-bar windows whose outgoing end is within `near_hint_bars` of the hint (or the closest end, if none are in range). Family costs match `nat_short` / `nat_long`.

It is not a blanket swap. With source lows in hand, a mid-track window is only added when:

1. The default natural window has an engine bass hole for more than 1 bar (the `GAP_DB=9.84` / `GAP_DB/2` lines above, already pro-calibrated; not loosened), and
2. The hint window has strictly fewer hole bars.

If the default window is already clean — for example `hybrid_minds_ukf__08`, default score 43.16, both-sides thin in a real outro, hole count 0 — the mid-track window is not nominated, and that pair is left alone. A blanket "always take the hint" dropped that pair to 18.74, which is the failure mode the listener was pointing at.

Defaults, `rules.json`, STRUCT, and X1 are unchanged. Tests: `src/tests/test_hint_family.py`.

On this pair the gate fires (14 hole bars vs 0) and the flag picks `hint_short` `["n", 112, null, 48, 16]`.

It is not claimed as a 5/5 match of Hybrid Minds' exact Demons cue, or as the right overlap length for every pair.
